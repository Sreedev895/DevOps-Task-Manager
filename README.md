# DevOps Task Manager

A Flask-based Task Manager application deployed on AWS EC2 using Docker and Jenkins CI/CD.

## Technologies Used
- AWS EC2
- Ubuntu Linux
- Python Flask
- SQLite
- Docker
- Docker Compose
- Git and GitHub
- Jenkins

## CI/CD Pipeline
1. Checkout source code from GitHub
2. Run automated tests
3. Build Docker image
4. Deploy application using Docker Compose
